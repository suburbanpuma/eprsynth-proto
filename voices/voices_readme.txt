included is the spanish language database SIN NOMBRE TESTER
it contains the following files.

doremi.wav - source samples
doremi_synth.wav - test render of the db
doremi.json - project file for the render

manifest.ini - db info
lang.ini - db phoneme info
base/g#3 - base style, g#3 pitch group
|- diphones - diphone model data
|- steady - sustain model data
|- vr.npz - voiced residual model data
|- index.json - db inventory and markers
